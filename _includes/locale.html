{%- comment -%} Resolve the active language once and expose interface/site copy. - `locale` : active language code (polyglot sets site.active_lang; falls back to site.locale, then 'it'). - `ui` : interface strings for `locale` (see _data/ui-text.yml). - `sitetext` : localized site copy for `locale` (see _data/site-text.yml). - `page_title` / `page_description` : prefer sitetext.pages[page.content_id] when set, else page front matter. Both lookups fall back to Italian when a locale is missing entirely, so templates can reference `ui.*` / `sitetext.*` safely. Include this at the top of any template/include that needs localized strings. Note: use `content_id` (not `page_id`) in front matter for this lookup. `page_id` is a reserved key for jekyll-polyglot's own translation-matching; reusing it here previously caused polyglot to populate `page.permalink_lang` with unresolved permalink templates (e.g. "about:output_ext"), breaking the language switcher. Keep the two concepts on separate keys. Post translations: same date + filename stem + `.en.md`/`.fr.md`, set `lang:` to `en`/`fr`. Permalinks follow the filename (lang_slug strips `.en`/ `.fr`); `title:` may differ per language. See README / _data/site-text.yml. {%- endcomment -%} {%- comment -%} `preview_lang` is true on /en/ and /fr/ while the translations are not yet announced (lang_switcher_public: false). Soft-launch previews stay noindex. Post bodies without a real `.en`/`.fr` file are not copied under /en|/fr (see _plugins/strip_post_fallbacks.rb). {%- endcomment -%} {%- assign preview_lang = false -%} {%- if site.active_lang and site.active_lang != site.default_lang and site.lang_switcher_public != true -%} {%- assign preview_lang = true -%} {%- endif -%} {%- comment -%} `lang_prefix` is '' on Italian and '/en' / '/fr' elsewhere. Templates use root-absolute paths, and polyglot prefixes plain `href` attributes on its own — so this is only needed where its rewriter does not reach: query-string URLs and paths inside JavaScript or JSON. {%- endcomment -%} {%- assign lang_prefix = '' -%} {%- if site.active_lang and site.active_lang != site.default_lang -%} {%- assign lang_prefix = '/' | append: site.active_lang -%} {%- endif -%} {%- assign locale = site.active_lang | default: site.locale | default: 'it' -%} {%- assign ui = site.data.ui-text[locale] | default: site.data.ui-text['it'] -%} {%- assign sitetext = site.data.site-text[locale] | default: site.data.site-text['it'] -%} {%- assign tag_labels = site.data.tag-labels[locale] -%} {%- assign page_title = page.title -%} {%- assign page_description = page.description -%} {%- if page.content_id and sitetext.pages[page.content_id] -%} {%- assign _page_loc = sitetext.pages[page.content_id] -%} {%- if _page_loc.title -%}{%- assign page_title = _page_loc.title -%}{%- endif -%} {%- if _page_loc.description -%}{%- assign page_description = _page_loc.description -%}{%- endif -%} {%- endif -%} {%- comment -%} Generated /tag/.html pages store the Italian tag key in page.tag_key; prefer the localized label for / Open Graph. {%- endcomment -%} {%- if page.tag_key -%} {%- if tag_labels and tag_labels[page.tag_key] -%} {%- assign page_title = tag_labels[page.tag_key] -%} {%- else -%} {%- assign page_title = page.tag_key -%} {%- endif -%} {%- endif -%}
