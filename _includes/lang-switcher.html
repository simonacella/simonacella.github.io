{% include locale.html %} {%- comment -%} Language switcher. Links use static_href so polyglot does not rewrite them. Every language version of a page shares the same permalink (see the pairing convention in README.md / _data/site-text.yml), so page.url is always the correct path — just prepend the target language's prefix. Deliberately NOT using page.permalink_lang here: polyglot populates it with the raw, unresolved `permalink:` front matter value (e.g. "about:output_ext" instead of "/about.html"), which produced broken switcher links. {%- endcomment -%}
